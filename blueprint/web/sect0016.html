Lean declarations

  • ParisHarringtonPrinciple.RelativelyLarge
  • ParisHarringtonPrinciple.IsHomogeneous

A finite set \(H\subseteq [1,N]\) is relatively large when \(|H|\ge m\) and \(\min H\le |H|\). It is homogeneous for a coloring when all of its \(k\)-subsets receive the same color.
